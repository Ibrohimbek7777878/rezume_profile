# rezume_profile — Ibrohim Sultonov | 3D Interactive Portfolio

Awwwards darajasidagi uzluksiz 3D portfolio-rezyume sayt.

**Stack:** React 18 + Vite 5 + TypeScript + Three.js (@react-three/fiber, @react-three/drei) + TailwindCSS + Framer Motion + GSAP + Zustand + Lenis

- Interaktiv WebGL / 3D tajriba (Three.js + postprocessing)

- Ko'p tilli (i18n) qo'llab-quvvatlash
